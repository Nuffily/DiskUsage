# -

Это программа для просмотра директорий на диске в TUI режиме, можно листать файлы, переходить из директории в директории и вести подсчет занятого пространства в папке

Запуск из консоли (возможен только из нее): ```python main.py```

Программа сделана при помощи библиотеки curses

Класс MenuMenu представляет собой самое начало, из которого можно перейти в:
- Класс InfoMenu, в котором просто немного написано о программе
- Класс DiskPickMenu, для выбора диска и перехода в DiskMenu. В POSIX системах переход сразу в DiskMenu

DiskMenu использует класс Scanner для определения занимаемого местам Formatter для отдельного форматирования строк
